# GeoInsight

GeoInsight is a German geospatial-AI company offering a Data-as-a-Service platform built on a Discrete Global Grid System (DGGS). It converts Earth-observation data into AI-ready hierarchical hexagonal 'Spatial Tokens' exposed via a standards-compliant OGC API - DGGS REST endpoint, starting with Sentinel-2 from the Copernicus archive.
